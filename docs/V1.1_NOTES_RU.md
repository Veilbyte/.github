# Изменения Policy Pack v1.1

1. Issue Forms перенесены в поддерживаемый GitHub путь `.github/ISSUE_TEMPLATE/`.
2. Уточнено, что `CODEOWNERS` действует только внутри конкретного репозитория и не наследуется из `Veilbyte/.github`.
3. Шаблон `CODEOWNERS` больше не ссылается на Secret-команды: команды-владельцы кода должны быть Visible и иметь явный Write-доступ к репозиторию.
4. Обновлены README и чек-листы развертывания.
