# Release Checklist

- [ ] Version follows Semantic Versioning.
- [ ] Release branch or PR is approved under repository rules.
- [ ] Build, tests, lint, formatting, dependency, secret, and security checks pass.
- [ ] Version references are updated.
- [ ] `CHANGELOG.md` is reviewed, even when a full release note is not required.
- [ ] Artifacts are produced by official CI or are traceable to the tagged source.
- [ ] No development secrets or debug endpoints are included.
- [ ] Upgrade and rollback paths are checked where applicable.
- [ ] Known security or compatibility risks are documented internally.
- [ ] Tag and release publisher are authorized.
