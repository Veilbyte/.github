# Контакты, которые нужно заполнить перед публикацией

Замените следующие значения во всех документах:

- `[VEILBYTE_SECURITY_EMAIL]` — приватный адрес для сообщений об уязвимостях.
- `[VEILBYTE_SECURITY_TELEGRAM]` — приватный Telegram-контакт или бот для security-репортов.
- `[VEILBYTE_GENERAL_EMAIL]` — общий контакт организации.
- `[VEILBYTE_BRAND_EMAIL]` — адрес для запросов на использование бренда и коммерческое лицензирование.
- `Onmaynec` — GitHub-логин владельца.
- `[COPYRIGHT_HOLDER]` — юридическое имя владельца прав.
- `[YEAR]` — год первой публикации конкретного проекта.

До заполнения контактов единственным официальным приватным каналом для публичных репозиториев считается GitHub Private Vulnerability Reporting, если он включён.
