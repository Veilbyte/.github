# Поддержка Veilbyte / Veilbyte Support

## Русский

### Каналы

- **GitHub Issues** — воспроизводимые ошибки, конкретные запросы функций, задачи и проблемы документации.
- **GitHub Discussions** — вопросы, идеи, помощь с использованием и общие обсуждения.
- **SECURITY.md** — только приватные сообщения об уязвимостях.

### Перед обращением

Проверьте README, документацию, существующие Issues и Discussions. Укажите версию, ОС, архитектуру, шаги воспроизведения, ожидаемый и фактический результат. Очистите логи от токенов, IP-адресов, cookies, имён, путей пользователя и других чувствительных данных.

### Что может быть закрыто

Незаполненные, дублирующиеся, не относящиеся к проекту, невоспроизводимые или нарушающие правила обращения могут быть закрыты без подробного ответа.

### Гарантии

Veilbyte не гарантирует сроки ответа, реализацию функции, исправление каждой ошибки или поддержку всех окружений. Приоритет получают безопасность, потеря данных, стабильность и проблемы актуальных версий.

## English

Use GitHub Issues for reproducible bugs, concrete feature requests, tasks, and documentation problems. Use GitHub Discussions for questions, ideas, and general support. Use `SECURITY.md` exclusively for private vulnerability reports.

Before posting, search existing documentation and reports. Include version, environment, reproduction steps, and expected/actual results. Sanitize all logs. Incomplete, duplicate, off-topic, unreproducible, or abusive reports may be closed without a detailed response.

Veilbyte does not guarantee response times, implementation of requested features, fixes for every bug, or support for every environment. Security, data-loss, stability, and current-version issues receive priority.
